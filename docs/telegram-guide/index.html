Ertebat
خانهمتدهای تلگرام

TELEGRAM BOT API

ساخت ربات تلگرام با Ertebat

از BotFather توکن بگیرید. این ماژول با Bot API تلگرام کار می‌کند و وابستگی جانبی ندارد.

نصب

pip install --upgrade ertebat

نمونه شروع

from ertebat import telegram
bot = telegram("TELEGRAM_BOT_TOKEN")

@bot.command("start")
async def start(bot, event):
    await event.reply("سلام! ربات تلگرام با Ertebat فعال شد ❤️")

@bot.message()
async def echo(bot, event):
    if event.text:
        await event.reply(event.text)

bot.run()

ارسال پیام

await bot.send_message(chat_id, "سلام از Ertebat")

دکمه اینلاین

keyboard = {"inline_keyboard": [[{"text": "باز کردن", "callback_data": "open"}]]}
await bot.send_message(chat_id, "یک گزینه انتخاب کن", reply_markup=keyboard)

@bot.callback()
async def callback(bot, event):
    await bot.answer_callback_query(event.callback_query_id, text="انتخاب شد")

دریافت پیام با long polling انجام می‌شود. اگر webhook فعال است، قبل از اجرای polling آن را غیرفعال کنید؛ این دو روش هم‌زمان قابل استفاده نیستند. توکن را محرمانه نگه دارید.
