راهنمای استفاده از ربات روبیکا

از نصب تا اجرای اولین ربات با IRubix

نصبساخت رباتدستوراتدریافت پیامCallbackارسال پیاماجرای رباتنکات

۱. نصب کتابخانه

با pip نصب کن:

pip install --upgrade https://github.com/adminVIPZEXNET/irubix/archive/refs/heads/main.zip

در محیط دارای Git:

pip install --upgrade git+https://github.com/adminVIPZEXNET/irubix.git

۲. ساخت نمونه ربات

from irubix import IRubix

bot = IRubix("YOUR_BOT_TOKEN")

به‌جای YOUR_BOT_TOKEN توکن ربات خودت را قرار بده.

۳. ساخت دستور با command

@bot.command("start")
async def start(bot, event):
    await event.reply("سلام! ربات فعاله.")

برای چند دستور می‌توانی یک فهرست بدهی:

@bot.command(["help", "about"])
async def help_handler(bot, event):
    await event.reply("راهنمای ربات")

۴. دریافت پیام‌ها

@bot.message()
async def echo(bot, event):
    if event.text:
        await event.reply(event.text)

می‌توانی تابع فیلتر هم به message بدهی تا فقط رویدادهای دلخواه پردازش شوند.

۵. دریافت Callback دکمه‌ها

@bot.callback()
async def on_callback(bot, event):
    print(event.button_id)

۶. ارسال پیام مستقل

import asyncio
from irubix import IRubix

bot = IRubix("YOUR_BOT_TOKEN")

async def main():
    result = await bot.send_text("CHAT_ID", "سلام از IRubix!")
    print(result)

asyncio.run(main())

۷. اجرای ربات

bot.run()

# یا در یک تابع async:
await bot.start()

برای توقف حلقه دریافت آپدیت‌ها، bot.stop() را فراخوانی کن.

نکات مهم

  • متدهای شبکه‌ای async هستند و باید با await فراخوانی شوند.
  • فاصله پیش‌فرض polling یک ثانیه است.
  • poll_interval نباید کمتر از ۰٫۱ ثانیه باشد و limit باید بین ۱ تا ۱۰۰ باشد.
  • توکن ربات را در مخزن عمومی یا کد منتشرشده قرار نده.
  • send_quiz در نسخه فعلی پیاده‌سازی نشده و خطای NotImplementedError می‌دهد.
