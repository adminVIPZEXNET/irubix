مستندات کتابخانه IRubix
خانهراهنمای روبیکامتدهای روبیکاراهنمای بلهمتدهای بلهراهنمای سروش‌پلاسمتدهای سروش‌پلاسخروجی‌هاسؤالات متداولGitHub

یک کتابخانه، سه پیام‌رسان

با IRubix برای روبیکا، بله و سروش‌پلاس ربات بسازید؛ با رابطی ساده و پایتون async.

راهنمای ربات روبیکامتدهای روبیکاشروع سریع ربات بلهمتدهای بلهشروع سریع سروش‌پلاسمتدهای سروش‌پلاستصاویر خروجیسؤالات متداولمخزن گیت‌هابکانال پشتیبانی روبیکا

نصب کتابخانه

برای نصب نسخه توسعه‌یافته:

pip install --upgrade https://github.com/adminVIPZEXNET/irubix/archive/refs/heads/main.zip

برای ساخت ربات سروش‌پلاس، راهنمای سروش‌پلاس را انتخاب کنید.
