SOROUSH PLUS API

مرجع متدهای سروش‌پلاس

متدهای پیاده‌سازی‌شده در کلاینت سروش‌پلاس IRubix نسخه 0.5.0

درخواست و اطلاعات بات

  • request(method, payload=None, http_method="POST") — فراخوانی مستقیم API
  • get_me() — دریافت اطلاعات بات
  • log_out() — خروج از سرور ابری
  • close() — بستن نمونه بات پیش از انتقال

دریافت به‌روزرسانی‌ها

  • get_updates(offset=None, limit=100, timeout=30, allowed_updates=None)
  • start(timeout=30, retry_delay=2) و run(...) — اجرای long polling
  • stop() — توقف polling

Webhook

  • set_webhook(url, **kwargs)
  • delete_webhook(drop_pending_updates=None)
  • get_webhook_info()

پیام‌ها

  • send_message(chat_id, text, **kwargs)
  • forward_message(chat_id, from_chat_id, message_id)
  • send_photo(chat_id, photo, caption=None, **kwargs)
  • send_document(chat_id, document, caption=None, **kwargs)
  • edit_message_text(chat_id, message_id, text, **kwargs)
  • delete_message(chat_id, message_id)
  • answer_callback_query(callback_query_id, **kwargs)
  • event.reply(text, **kwargs)

ثبت handler

  • command(names) — دریافت فرمان‌ها
  • message(flt=None) — دریافت پیام‌ها
  • callback() — دریافت callback query

کلاس‌ها و خطاها

  • soroush و نام جایگزین soroush.Bot
  • soroush.Event — شیء رویداد ورودی
  • soroush.SoroushAPIError — خطای API یا ارتباط
