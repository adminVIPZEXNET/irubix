SOROUSH PLUS BOT API · IRUBIX 0.5.0

مرجع کامل متدهای سروش‌پلاس

این مرجع از روی پیاده‌سازی فعلی irubix/soroush/bot.py تهیه شده است. امضاها و گزینه‌ها مطابق wrapper همین نسخه‌اند.

ساخت کلاینت و خطا

from irubix import soroush

bot = soroush("SOROUSH_BOT_TOKEN", timeout=40)

سازنده: IRubix(token=None, *, timeout=40, base_url=None) · خطا: SoroushAPIError · نام مستعار کلاس: soroush.Bot.

درخواست و اطلاعات ربات

  • await bot.request(method, payload=None, http_method="POST") — درخواست مستقیم؛ متد HTTP قابل تعیین است.
  • await bot.get_me() — اطلاعات ربات.
  • await bot.log_out() — فراخوانی endpoint خروج از سرور ابری؛ قبل از استفاده، اثر آن بر نشست ربات را بررسی کنید.
  • await bot.close() — فراخوانی endpoint بستن نمونه ربات.

دریافت Update و Webhook

  • await bot.get_updates(*, offset=None, limit=100, timeout=30, allowed_updates=None) — دریافت Updateها؛ limit بین 1 تا 100 و timeout نامنفی است.
  • await bot.set_webhook(url, **kwargs) — ثبت webhook؛ گزینه‌های عبوری: ip_address، max_connections، drop_pending_updates، allowed_updates و certificate.
  • await bot.delete_webhook(*, drop_pending_updates=None) — حذف webhook و در صورت تعیین، پاک‌کردن Updateهای منتظر.
  • await bot.get_webhook_info() — دریافت وضعیت webhook.

پیام‌ها و رسانه

  • await bot.send_message(chat_id, text, **kwargs) — گزینه‌های مجاز: parse_mode، entities، reply_markup، disable_web_page_preview، reply_to_message_id و allow_sending_without_reply.
  • await bot.forward_message(chat_id, from_chat_id, message_id) — فوروارد پیام.
  • await bot.send_photo(chat_id, photo, caption=None, **kwargs) — ارسال عکس با file_id یا URL؛ گزینه‌های parse_mode، reply_markup و reply_to_message_id.
  • await bot.send_document(chat_id, document, caption=None, **kwargs) — ارسال سند با file_id یا URL؛ همان گزینه‌های رسانه‌ای عکس.
  • await bot.edit_message_text(chat_id, message_id, text, **kwargs) — ویرایش متن؛ گزینه‌های parse_mode، entities، reply_markup و disable_web_page_preview.
  • await bot.delete_message(chat_id, message_id) — حذف پیام.
  • await bot.answer_callback_query(callback_query_id, **kwargs) — پاسخ به callback؛ گزینه‌ها: text، show_alert، url و cache_time.
  • await event.reply(text, **kwargs) — پاسخ به پیام جاری و تنظیم خودکار reply_to_message_id در صورت وجود شناسه پیام.

ثبت handler و Event

  • @bot.command(names) — ثبت یک یا چند فرمان.
  • @bot.message(flt=None) — ثبت handler پیام با فیلتر callable اختیاری.
  • @bot.callback() — ثبت handler callback query.

فیلدهای Event: raw، update، message، chat، chat_id، message_id، text، sender، sender_id، callback_query، button_id و type. شناسه callback از event.callback_query["id"] قابل دریافت است.

from irubix import soroush

bot = soroush("SOROUSH_BOT_TOKEN")

@bot.command("start")
async def start(bot, event):
    await event.reply("ربات سروش‌پلاس آماده است")

@bot.message(lambda event: event.text == "سلام")
async def hello(bot, event):
    await event.reply("سلام!")

@bot.callback()
async def callback(bot, event):
    query = event.callback_query
    if query:
        await bot.answer_callback_query(query["id"], text="ثبت شد")

bot.run()

اجرای polling

  • await bot.start(*, timeout=30, retry_delay=2) — شروع long polling.
  • bot.stop() — توقف حلقه polling.
  • bot.run(*, timeout=30, retry_delay=2) — اجرای ساده؛ در event loop فعال coroutine را برمی‌گرداند.

توجه: در یک زمان از یک روش دریافت Update (polling یا webhook) استفاده کنید. log_out() و close() عملیات مربوط به نشست هستند، نه متدهای معمول ارسال پیام.
