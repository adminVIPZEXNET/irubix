مرجع کلاس Shad

کلاس shad.Shad از پیاده‌سازی حساب کاربری MAXRubika ارث‌بری می‌کند. این کلاس Bot API نیست و با نشست حساب کاربری کار می‌کند.

سازنده

shad.Shad(
    session=None,
    string_session=None,
    password=None,
    auth=None,
    private_key=None,
    timeout=30,
    proxy=None,
    logger=None,
    platform="shad_web",
    api_version=6,
    max_retries=5,
    stop_on_first_match=False,
    run_all_handlers=None,
    continue_on_error=True,
    as_dict=False,
    show_welcome=False
)

پلتفرم‌ها

  • shad_web — نسخه وب
  • shad_pwa — نسخه PWA
  • shad_android — نسخه اندروید

دسته‌بندی قابلیت‌های به‌ارث‌رسیده

  • اتصال، شروع و قطع اتصال: connect()، start()، run()، stop()، close()
  • رویدادها: on_message()، on_new_message()، on_edit_message()، on_delete_message()
  • پیام‌ها: ارسال، ویرایش، حذف، پاسخ و فوروارد پیام
  • رسانه: ارسال و دریافت فایل، تصویر، ویدئو، صدا و فایل‌های رسانه‌ای
  • گفتگوها، گروه‌ها و کانال‌ها: مدیریت گفتگوها، اعضا و اطلاعات آن‌ها
  • کاربران و حساب: اطلاعات کاربر، تنظیمات حساب و نشست
  • فیلترها: فیلتر متن، فرستنده، نوع گفتگو و رسانه

نمونه

from irubix import shad

app = shad.Shad(session="my_shad_session", platform="shad_web")

@app.on_new_message()
async def handler(event):
    print(event.text)
    await event.reply("دریافت شد")

app.run()

توجه: وجود یک متد در کلاس پایه تضمین نمی‌کند که endpoint متناظر در سرور شاد فعال باشد. پشتیبانی هر متد باید با حساب آزمایشی بررسی شود. برای فهرست کامل متدها و پارامترها به مستندات MAXRubika مراجعه کنید.
