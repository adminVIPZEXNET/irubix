SHAD USER CLIENT

مرجع کلاس Shad

کلاس shad.Shad برای حساب کاربری و نشست API v6 طراحی شده است.

سازنده

shad.Shad(session=None, auth=None, private_key=None, platform="shad_web", timeout=30, proxy=None, api_version=6, max_retries=3, logger=None)

متدها

  • connect() — دریافت نشانی‌های API
  • close() — بستن اتصال
  • request(method, input={}) — درخواست رمزنگاری‌شده API v6
  • get_me() — دریافت اطلاعات حساب
  • send_message(chat, text, reply_to_message_id=None) — ارسال پیام متنی
  • on_new_message() — ثبت handler پیام جدید
  • run() — دریافت رویدادها از WebSocket
  • stop() — توقف حلقه دریافت

نمونه

from irubix import shad
app = shad.Shad(session="my_shad_session.json")
@app.on_new_message()
async def handler(event):
    print(event.text)
    await event.reply("دریافت شد")
app.run()

توجه: این نسخه بر API v6 و نشست موجود متمرکز است. احراز هویت اولیه با شماره تلفن، ارسال رسانه و مدیریت گروه/کانال هنوز پیاده‌سازی نشده‌اند.
