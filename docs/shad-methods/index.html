مرجع متدهای شاد

متدهای ارائه‌شده در کلاینت شاد IRubix نسخه 0.6.0. این API در منابع عمومی غیررسمی مستند شده است.

  • get_me()
  • get_updates(limit=10, offset_id=None)
  • start(limit=10, retry_delay=2)، run(...)، stop()

  • edit_message_text(chat_id, message_id, text)
  • delete_message(chat_id, message_id)
  • send_poll(chat_id, question, options, **kwargs)
  • send_location(chat_id, latitude, longitude, **kwargs)
  • send_sticker(chat_id, sticker_id, **kwargs)
  • send_contact(chat_id, first_name, last_name, phone_number, **kwargs)
  • send_file(chat_id, file_id, **kwargs)
