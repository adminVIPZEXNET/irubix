BALE BOT API · IRUBIX 0.4.0

مرجع کامل متدهای بله

این صفحه بر اساس سورس واقعی irubix/bale/bot.py نوشته شده است. فقط موارد زیر در کلاینت فعلی پیاده‌سازی شده‌اند؛ وجود یک endpoint در API بله به‌تنهایی به معنی وجود متد آماده برای آن در IRubix نیست.

ساخت کلاینت و خطا

from irubix import bale

bot = bale("BALE_BOT_TOKEN", timeout=40)
# base_url اختیاری است: bale("TOKEN", base_url="https://tapi.bale.ai")

سازنده: IRubix(token=None, *, timeout=40, base_url=None) · خطا: BaleAPIError · نام مستعار کلاس: bale.Bot.

درخواست و اطلاعات

  • await bot.request(method, payload=None) — فراخوانی مستقیم متد Bot API بله. نام متد نباید خالی یا شامل / باشد.
  • await bot.get_me() — دریافت اطلاعات ربات.
  • await bot.get_updates(*, offset=None, limit=100, timeout=30) — دریافت Updateها با long polling.

ارسال و مدیریت پیام

  • await bot.send_message(chat_id, text, **kwargs) — پارامترهای اضافی مجاز در wrapper: reply_to_message_id، reply_markup، parse_mode، disable_notification، protect_content و message_thread_id.
  • await bot.send_photo(chat_id, photo, caption=None, **kwargs) — ارسال عکس با file_id یا URL؛ reply_to_message_id پشتیبانی می‌شود.
  • await bot.send_document(chat_id, document, caption=None, **kwargs) — ارسال سند با file_id یا URL؛ reply_to_message_id پشتیبانی می‌شود.
  • await bot.edit_message_text(chat_id, message_id, text, **kwargs) — ویرایش متن؛ reply_markup اختیاری.
  • await bot.delete_message(chat_id, message_id) — حذف پیام.
  • await event.reply(text, **kwargs) — پاسخ به پیام جاری؛ برای callback نیز چت و پیام مربوط به callback را پیدا می‌کند و از send_message استفاده می‌کند.

ثبت handler و رویداد

  • @bot.command(names) — ثبت یک دستور یا فهرستی از دستورها؛ نام دستور را با یا بدون / می‌پذیرد.
  • @bot.message(flt=None) — ثبت handler پیام؛ flt در صورت callable بودن به‌عنوان فیلتر رویداد اجرا می‌شود.
  • @bot.callback() — ثبت handler برای callback query.

فیلدهای Event: raw و update (داده خام)، message، chat، chat_id، message_id، text، sender، sender_id، callback_query، button_id و type.

from irubix import bale

bot = bale("BALE_BOT_TOKEN")

@bot.command(["start", "help"])
async def commands(bot, event):
    await event.reply("سلام از بله")

@bot.message(lambda event: event.text == "سلام")
async def hello(bot, event):
    await event.reply("سلام!")

@bot.callback()
async def buttons(bot, event):
    print(event.button_id, event.callback_query)

bot.run()

اجرای polling

  • await bot.start(*, timeout=30, retry_delay=2) — شروع long polling تا زمان فراخوانی stop؛ timeout باید بین 0 و 50 باشد.
  • bot.stop() — درخواست توقف حلقه polling.
  • bot.run(*, timeout=30, retry_delay=2) — اجرای ساده؛ اگر event loop فعال باشد coroutine شروع را برمی‌گرداند.

آنچه در کلاینت بله فعلی وجود ندارد

در این نسخه wrapperهای اختصاصی get_chat، forward_message، answer_callback_query، send_audio، send_video، send_location، set_webhook و send_file پیاده‌سازی نشده‌اند. برای endpointهای دیگر می‌توان از request() استفاده کرد، مشروط به اینکه پارامترهای API را مطابق مستندات رسمی ارسال کنید. آپلود فایل محلی در متدهای رسانه‌ای فعلی انجام نمی‌شود.
