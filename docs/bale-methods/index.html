BALE API

مرجع متدهای بله

متدهای موجود در کلاینت بله نسخه 0.4.0

مدیریت و دریافت رویداد

  • get_me() — دریافت اطلاعات ربات
  • get_updates(offset=None, limit=100, timeout=30) — دریافت به‌روزرسانی‌ها
  • command(names) — ثبت دستور
  • message(flt=None) — ثبت handler پیام
  • callback() — ثبت handler دکمه callback
  • start(timeout=30) / run(timeout=30) — اجرای polling
  • stop() — توقف polling

پیام‌ها

  • send_message(chat_id, text, **kwargs)
  • send_photo(chat_id, photo, caption=None)
  • send_document(chat_id, document, caption=None)
  • edit_message_text(chat_id, message_id, text)
  • delete_message(chat_id, message_id)
  • event.reply(text, **kwargs)

خطاها

خطاهای ارتباطی یا پاسخ ناموفق API با BaleAPIError گزارش می‌شوند.
