نمونه‌کدهای کامل و قابل اجرا برای متدها

هر کد زیر را می‌توانی جداگانه در یک فایل پایتون ذخیره و اجرا کنی. مقدار YOUR_BOT_TOKEN و شناسه‌های نمونه را با مقادیر واقعی جایگزین کن. متدهای شبکه‌ای به توکن معتبر و دسترسی لازم نیاز دارند. تصویرهای خروجی کنار هر مثال، تصویرهای نمونه و شبیه‌سازی‌شده برای نمایش شکل نتیجه هستند؛ پاسخ واقعی API فقط پس از اجرای کد با توکن و شناسه‌های معتبر به دست می‌آید و ممکن است متفاوت باشد.

نمونه کامل: ساخت ربات و دستور start

from irubix import Rubika

bot = Rubika("YOUR_BOT_TOKEN")

@bot.command("start")
async def start(bot, event):
    await event.reply("سلام! خوش اومدی ❤️")

bot.run()

نمونه خروجی و تصویر ترمینال

مشاهده گالری تمام ۲۰ تصویر خروجی متدها ←

کدهای این مرجع پاسخ JSON یا نتیجه handler را چاپ می‌کنند. تصویر زیر یک نمونه نمایشی از شکل پاسخ موفق API است، نه نتیجه اجرای توکن واقعی. مقادیر شناسه‌ها نمونه‌اند و در اجرای واقعی متفاوت خواهند بود.

برای متدهای تغییردهنده مانند ارسال، حذف، ویرایش و مسدودسازی، خروجی واقعی فقط با شناسه‌های یک چت آزمایشی قابل ثبت است. متد send_quiz نیز در نسخه فعلی پیاده‌سازی نشده است.

event.rawداده خام آپدیت
event.updateهمان داده خام آپدیت
event.typeنوع رویداد
event.update_typeنوع آپدیت
event.messageاطلاعات پیام به شکل دیکشنری
event.chat_idشناسه گفتگو
event.message_idشناسه پیام
event.textمتن پیام یا رشته خالی
event.sender_idشناسه فرستنده
event.button_idشناسه یا داده callback
event.reply(text, **kwargs)پاسخ به پیام فعلی و در صورت وجود، ریپلای به آن
