BALE BOT API

ساخت ربات بله با IRubix

از نسخه 0.4.0 می‌توانید با همان سبک ساده، برای پیام‌رسان بله ربات بسازید. بخش بله مستقل از کلاینت روبیکاست.

نصب

pip install --upgrade irubix

اولین ربات

from irubix import bale

bot = bale.IRubix("BALE_BOT_TOKEN")

@bot.command("start")
async def start(bot, event):
    await event.reply("سلام! خوش اومدی ❤️")

bot.run()

دریافت همه پیام‌ها

@bot.message()
async def all_messages(bot, event):
    print(event.text, event.chat_id)
    await event.reply("پیامت دریافت شد.")

ارسال پیام

await bot.send_message(chat_id, "سلام از IRubix")

نکته‌ها

  • توکن را داخل کد عمومی یا مخزن Git قرار ندهید.
  • برای polling، ربات نباید هم‌زمان webhook فعال داشته باشد.
  • این نسخه از long polling و متدهای پایه پیام پشتیبانی می‌کند؛ قابلیت‌های پیشرفته‌تر در حال توسعه‌اند.
