TELEGRAM BOT API

مرجع کلاس Telegram

کلاس اصلی telegram(token) و نام مستعار telegram.Bot(token) است.

متدها

  • request(method, payload=None) — فراخوانی Bot API
  • get_me() — اطلاعات ربات
  • get_chat(chat_id) — اطلاعات گفتگو
  • get_updates(offset=None, limit=100, timeout=30) — دریافت آپدیت
  • send_message(chat_id, text, **kwargs) — ارسال متن
  • send_photo(chat_id, photo, caption=None, **kwargs) — ارسال عکس با file_id یا URL
  • send_document(chat_id, document, caption=None, **kwargs) — ارسال سند با file_id یا URL
  • forward_message(chat_id, from_chat_id, message_id) — فوروارد
  • edit_message_text(chat_id, message_id, text, **kwargs) — ویرایش متن
  • delete_message(chat_id, message_id) — حذف پیام
  • answer_callback_query(callback_query_id, **kwargs) — پاسخ callback

مدیریت رویداد

  • command(names) — ثبت دستور
  • message(flt=None) — ثبت پیام با فیلتر اختیاری
  • callback() — ثبت callback
  • start(timeout=30, retry_delay=2)، stop() و run() — کنترل polling

ویژگی Event

event.text، event.chat_id، event.message_id، event.sender_id، event.button_id، event.callback_query_id و await event.reply(text).

from irubix import telegram
bot = telegram("TOKEN")
@bot.command("start")
async def start(bot, event):
    await event.reply("سلام")
bot.run()
