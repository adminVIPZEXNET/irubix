SOROUSH PLUS BOT API

ساخت ربات سروش‌پلاس با IRubix

از نسخه 0.5.0 می‌توانید با ماژول مستقل سروش‌پلاس، ربات خود را با رابط async و decorator بسازید. توکن ربات را از BotFather سروش‌پلاس دریافت کنید.

نصب

pip install --upgrade irubix

اولین ربات

from irubix import soroush

bot = soroush("SOROUSH_BOT_TOKEN")

@bot.command("start")
async def start(bot, event):
    await event.reply("سلام! به ربات من خوش اومدی ❤️")

bot.run()

دریافت همه پیام‌ها

@bot.message()
async def all_messages(bot, event):
    print(event.text, event.chat_id)
    await event.reply("پیامت دریافت شد.")

ارسال پیام به یک چت

await bot.send_message(chat_id, "سلام از IRubix")

دکمه‌های callback

@bot.callback()
async def buttons(bot, event):
    print(event.button_id)
    await bot.answer_callback_query(event.callback_query["id"])

دریافت اطلاعات بات

me = await bot.get_me()
print(me)

Webhook

await bot.set_webhook("https://example.com/webhook/SECRET_PATH")
info = await bot.get_webhook_info()
await bot.delete_webhook()

نکته‌های مهم

  • توکن را در کد عمومی یا مخزن Git قرار ندهید.
  • برای استفاده از long polling، webhook فعال را حذف کنید.
  • سروش‌پلاس به آدرس API مستقل https://api.splus.ir متصل می‌شود.
  • فایل‌های ارسالی با URL یا file_id قابل استفاده‌اند؛ محدودیت‌های آپلود و دانلود را در مستندات رسمی بررسی کنید.
