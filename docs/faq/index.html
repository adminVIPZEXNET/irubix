سؤالات متداول

پاسخ کوتاه به سؤال‌ها و خطاهای رایج هنگام شروع کار با Ertebat.

چطور نصب کنم؟

در Pydroid 3 یا ترمینال، دستور نصب صفحه اصلی را اجرا کن. برای نصب از Git لازم نیست؛ فایل ZIP مخزن هم قابل نصب است.

آیا به پکیج دیگری نیاز دارم؟

خیر. طبق تنظیمات فعلی پروژه، کتابخانه در زمان اجرا فقط از کتابخانه‌های استاندارد Python استفاده می‌کند. ابزار نصب ممکن است setuptools را استفاده کند.

چرا باید از await استفاده کنم؟

متدهای شبکه‌ای Ertebat ناهمگام هستند. داخل handlerها و توابع async باید آن‌ها را با await صدا بزنی.

ربات پیام‌ها را دریافت نمی‌کند؛ چه کنم؟

  • توکن را دقیق بررسی کن و مطمئن شو فاصله اضافه ندارد.
  • اتصال اینترنت و دسترسی برنامه به اینترنت را بررسی کن.
  • مطمئن شو برنامه در حال اجراست و خطای API در خروجی چاپ نشده است.
  • برای تست، ابتدا نمونه ساده دستور start در راهنما را اجرا کن.

آیا send_quiz فعال است؟

خیر. در نسخه فعلی عمداً پیاده‌سازی نشده و NotImplementedError می‌دهد؛ آن را قابلیت آماده در نظر نگیر.

کجا خطا گزارش کنم؟

در بخش Issues مخزن GitHub، نسخه Python، نسخه Ertebat، متن کامل خطا و یک نمونه کوچک از کد را بفرست. توکن ربات و اطلاعات محرمانه را حذف کن.
