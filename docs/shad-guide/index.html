SHAD USER CLIENT

کار با حساب کاربری شاد

ماژول شاد برای اتصال به حساب کاربری طراحی شده است، نه ساخت ربات. این ماژول از کلاس Shad کتابخانه MAXRubika استفاده می‌کند و رابط آن را در فضای نام IRubix ارائه می‌دهد.

نصب

pip install --upgrade https://github.com/adminVIPZEXNET/irubix/archive/refs/heads/main.zip

وابستگی MAXRubika به‌صورت خودکار همراه IRubix نصب می‌شود.

ساخت کلاینت

from irubix import shad

app = shad.Shad(
    session="my_shad_session",
    platform="shad_web"
)

دریافت پیام‌ها

@app.on_new_message()
async def handler(event):
    print(event.text)
    await event.reply("سلام ❤️")

app.run()

انتخاب پلتفرم

# نسخه وب
app = shad.Shad(session="shad_session", platform="shad_web")

# نسخه PWA
app = shad.Shad(session="shad_session", platform="shad_pwa")

# نسخه اندروید
app = shad.Shad(session="shad_session", platform="shad_android")

ورود و نشست

پارامتر session مسیر فایل نشست است. در صورت نداشتن نشست معتبر، متد start() فرایند احراز هویت را آغاز می‌کند و ممکن است شماره تلفن و کد تأیید بخواهد. از انتشار فایل نشست، auth و کلید خصوصی خودداری کنید.

متدها

کلاس Shad متدهای حساب کاربری و handlerهای MAXRubika را به ارث می‌برد. فهرست متدهای پایه را در مستندات MAXRubika ببینید. همه متدهای روبیکا الزاماً از طرف سرور شاد پشتیبانی نمی‌شوند.
