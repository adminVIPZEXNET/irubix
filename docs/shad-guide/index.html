SHAD USER CLIENT

کار با حساب کاربری شاد

ماژول شاد یک کلاینت مستقل حساب کاربری است و به توکن ربات نیاز ندارد.

نصب

pip install --upgrade irubix

ساخت کلاینت

from irubix import shad
app = shad.Shad(session="my_shad_session.json", platform="shad_web")

فایل نشست JSON باید شامل auth و private_key باشد. مقدار guid نیز در صورت دسترس قابل ذخیره است.

دریافت پیام‌ها

@app.on_new_message()
async def handler(event):
    print(event.text)
    await event.reply("سلام ❤️")
app.run()

ارسال پیام

await app.send_message("CHAT_GUID", "سلام از IRubix")

محدودیت نسخه

این نسخه API v6 و نشست موجود را پشتیبانی می‌کند. ورود اولیه با شماره تلفن و کد تأیید و متدهای پیشرفته رسانه‌ای و مدیریتی هنوز پیاده‌سازی نشده‌اند.

فایل نشست و کلید خصوصی را در مخزن عمومی قرار ندهید.
