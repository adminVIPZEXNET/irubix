SHAD BOT API

ساخت ربات شاد با IRubix

ماژول شاد با رابط async و decorator در IRubix ارائه شده است. توجه کنید که رابط Bot API شاد در منابع عمومی موجود، غیررسمی مستند شده و ممکن است تغییر کند؛ در حال حاضر مستندات رسمی عمومی و تضمین سازگاری از سوی شاد در دسترس نیست.

نصب نسخه توسعه

pip install --upgrade https://github.com/adminVIPZEXNET/irubix/archive/refs/heads/main.zip

نمونه شروع

from irubix import shad

bot = shad.IRubix("SHAD_BOT_TOKEN")

@bot.command("start")
async def start(bot, event):
    await event.reply("سلام! به ربات شاد خوش اومدی ❤️")

@bot.message()
async def messages(bot, event):
    print(event.text)

bot.run()

ارسال پیام

await bot.send_message("CHAT_ID", "سلام از IRubix")

اطلاعات ربات و گفتگو

me = await bot.get_me()
chat = await bot.get_chat("CHAT_ID")
print(me, chat)

فایل و رسانه

upload = await bot.request_send_file("File")
await bot.send_file("CHAT_ID", upload["file_id"])

نکات

  • توکن ربات را در مخزن عمومی یا پیام‌ها منتشر نکنید.
  • نام متدها و قالب Updateها بر اساس پیاده‌سازی عمومی shad-api برداشت شده‌اند و ممکن است با تغییرات سمت سرور نیازمند اصلاح باشند.
  • این ماژول Selenium یا ورود با شماره تلفن را استفاده نمی‌کند؛ هدف آن اتصال به endpoint ربات است.
