۱. روبیکا

واردسازی: from irubix import Rubika · کلاس جایگزین: Bot · خطا: RubikaAPIError

ساخت ربات، دستور و دریافت پیام

from irubix import Rubika

bot = Rubika.IRubix("YOUR_BOT_TOKEN")

@bot.command("start")
async def start(bot, event):
    await event.reply("سلام! ربات فعاله.")

@bot.message()
async def messages(bot, event):
    if event.text:
        await event.reply(event.text)

@bot.callback()
async def buttons(bot, event):
    print(event.button_id)

bot.run()

ارسال پیام مستقل

import asyncio
from irubix import Rubika

bot = Rubika.IRubix("YOUR_BOT_TOKEN")
CHAT_ID = "YOUR_CHAT_ID"

async def main():
    result = await bot.send_text(CHAT_ID, "سلام از IRubix")
    print(result)

asyncio.run(main())

ارسال فایل محلی (send_file)

import asyncio
from irubix import Rubika

bot = Rubika.IRubix("YOUR_BOT_TOKEN")
CHAT_ID = "YOUR_CHAT_ID"

async def main():
    result = await bot.send_file(
        CHAT_ID,
        "photo.jpg",
        text="تصویر من",
        file_type="Image"
    )
    print(result)

asyncio.run(main())

پارامتر path مسیر فایل یا داده باینری است. برای داده باینری می‌توانید نام را با file_name تعیین کنید.

متدهای موجود

  • request(method, input=None)
  • get_me()، get_chat(chat_id)، get_file(file_id)
  • send_text(chat_id, text, **kwargs)، send_message(chat_id, text, **kwargs)
  • send_file(chat_id, path, text=None, file_type="File", **kwargs)
  • send_poll(chat_id, question, options)؛ send_quiz() فعلاً پیاده‌سازی نشده است.
  • forward_message(...)، edit_message_text(...)، delete_message(...)
  • ban_chat_member(...)، unban_chat_member(...)
  • command(names)، message(flt=None)، callback()
  • start(poll_interval=1.0, limit=100)، stop()، run(...)، event.reply(text, **kwargs)

۳. سروش‌پلاس

واردسازی: from irubix import soroush · کلاس: soroush.IRubix یا soroush.Bot · خطا: SoroushAPIError

ساخت ربات و دریافت پیام

from irubix import soroush

bot = soroush.IRubix("SOROUSH_BOT_TOKEN")

@bot.command("start")
async def start(bot, event):
    await event.reply("سلام! ربات سروش‌پلاس فعاله.")

@bot.message()
async def messages(bot, event):
    if event.text:
        await event.reply(event.text)

@bot.callback()
async def buttons(bot, event):
    print(event.button_id)
    if event.callback_query:
        await bot.answer_callback_query(event.callback_query["id"])

bot.run()

الگوی مشترک Event

@bot.message()
async def handle(bot, event):
    print(event.text)
    print(event.chat_id)
    print(event.message_id)
    await event.reply("پیام دریافت شد")

برای فیلتر پیام:

@bot.message(lambda event: event.text == "سلام")
async def hello(bot, event):
    await event.reply("سلام به شما!")

فیلدهای Event بسته به پیام‌رسان متفاوت‌اند؛ برای داده کامل رویداد از event.raw استفاده کنید.

نکات

  • روبیکا از from irubix import Rubika استفاده می‌کند؛ بقیه از ماژول اختصاصی خودشان.
  • برای اجرای ربات از bot.run() استفاده کنید.
  • توکن را در GitHub یا کد عمومی قرار ندهید.
  • متد send_file برای ارسال فایل محلی فعلاً مختص روبیکاست.

مثال کدنویسی تمام متدها

در این بخش برای تک‌تک متدهای عمومی هر کلاینت، نمونه فراخوانی قرار داده شده است. مقادیر نمونه مثل توکن، شناسه گفتگو، شناسه پیام و file_id را با اطلاعات واقعی خود جایگزین کنید. نمونه‌های مدیریتی را فقط در گروهی که مجاز به مدیریت آن هستید اجرا کنید.

import asyncio
from irubix import Rubika

bot = Rubika.IRubix("YOUR_BOT_TOKEN")

async def main():
    me = await bot.get_me()
    chat = await bot.get_chat("YOUR_CHAT_ID")

    # فراخوانی مستقیم یکی از متدهای رسمی API
    result = await bot.request("getMe", {})
    print(me, chat, file_info, result)

asyncio.run(main())

Decoratorها، پاسخ رویداد و اجرای ربات:

from irubix import Rubika

@bot.command(["start", "help"])

اجرای دستی polling و توقف:

import asyncio
from irubix import Rubika

bot = Rubika.IRubix("YOUR_BOT_TOKEN")

async def main():
    # اجرای polling تا زمانی که task لغو یا bot متوقف شود
    task = asyncio.create_task(bot.start(poll_interval=1.0, limit=100))
    await asyncio.sleep(10)
    bot.stop()
    await task

asyncio.run(main())

متد send_quiz در کد وجود دارد اما عمداً NotImplementedError می‌دهد؛ حالت Quiz در API فعلی روبیکا پشتیبانی نشده است. برای نظرسنجی از send_poll استفاده کنید.

Decoratorها، Event و اجرای polling:

from irubix import telegram

bot = telegram.IRubix("TELEGRAM_BOT_TOKEN")

@bot.command("start")
async def start(bot, event):
    await event.reply("ربات تلگرام آماده است")

@bot.message()
async def messages(bot, event):
    print(event.text, event.chat_id, event.sender_id)
    await event.reply(event.text or "پیام دریافت شد")

@bot.message(lambda event: event.text == "سلام")
async def filtered(bot, event):
    await event.reply("سلام!")

@bot.callback()
async def callbacks(bot, event):
    await bot.answer_callback_query(
        event.callback_query_id,
        text="انتخاب شما ثبت شد"
    )

bot.run(timeout=30, retry_delay=2)

import asyncio

نکته درباره تفاوت متدها

  • روبیکا متد send_file برای آپلود فایل محلی دارد؛ در سه کلاینت دیگر چنین متدی در پیاده‌سازی فعلی وجود ندارد.
  • در بله و تلگرام برای ارسال عکس و سند از file_id یا URL استفاده شده است؛ در سروش‌پلاس نیز ورودی متدهای رسانه‌ای فعلی file_id یا URL است.
  • سروش‌پلاس متدهای Webhook، log_out و close را دارد؛ این متدها در کلاینت‌های دیگر این مخزن وجود ندارند.
  • روبیکا متدهای مدیریتی ban/unban و نظرسنجی دارد؛ send_quiz فقط placeholder است و قابل استفاده عملی نیست.
  • متدهای _request_sync، _dispatch و _upload_sync داخلی هستند و جزو API عمومی مستندشده نیستند.
