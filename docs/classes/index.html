۱. روبیکا

واردسازی: from irubix import IRubix · کلاس جایگزین: Bot · خطا: RubikaAPIError

ساخت ربات، دستور و دریافت پیام

from irubix import IRubix

bot = IRubix("YOUR_BOT_TOKEN")

@bot.command("start")
async def start(bot, event):
    await event.reply("سلام! ربات فعاله.")

@bot.message()
async def messages(bot, event):
    if event.text:
        await event.reply(event.text)

@bot.callback()
async def buttons(bot, event):
    print(event.button_id)

bot.run()

ارسال پیام مستقل

import asyncio
from irubix import IRubix

bot = IRubix("YOUR_BOT_TOKEN")
CHAT_ID = "YOUR_CHAT_ID"

async def main():
    result = await bot.send_text(CHAT_ID, "سلام از IRubix")
    print(result)

asyncio.run(main())

ارسال فایل محلی (send_file)

import asyncio
from irubix import IRubix

bot = IRubix("YOUR_BOT_TOKEN")
CHAT_ID = "YOUR_CHAT_ID"

async def main():
    result = await bot.send_file(
        CHAT_ID,
        "photo.jpg",
        text="تصویر من",
        file_type="Image"
    )
    print(result)

asyncio.run(main())

پارامتر path مسیر فایل یا داده باینری است. برای داده باینری می‌توانید نام را با file_name تعیین کنید.

متدهای موجود

  • request(method, input=None)
  • get_me()، get_chat(chat_id)، get_file(file_id)
  • send_text(chat_id, text, **kwargs)، send_message(chat_id, text, **kwargs)
  • send_file(chat_id, path, text=None, file_type="File", **kwargs)
  • send_poll(chat_id, question, options)؛ send_quiz() فعلاً پیاده‌سازی نشده است.
  • forward_message(...)، edit_message_text(...)، delete_message(...)
  • ban_chat_member(...)، unban_chat_member(...)
  • command(names)، message(flt=None)، callback()
  • start(poll_interval=1.0, limit=100)، stop()، run(...)، event.reply(text, **kwargs)

۲. بله

واردسازی: from irubix import bale · کلاس: bale.IRubix یا bale.Bot · خطا: BaleAPIError

ساخت ربات و دریافت پیام

from irubix import bale

bot = bale.IRubix("BALE_BOT_TOKEN")

@bot.command("start")
async def start(bot, event):
    await event.reply("سلام! ربات بله فعاله.")

@bot.message()
async def messages(bot, event):
    if event.text:
        await event.reply(event.text)

@bot.callback()
async def buttons(bot, event):
    print(event.button_id)

bot.run()

ارسال متن، عکس و سند

import asyncio
from irubix import bale

bot = bale.IRubix("BALE_BOT_TOKEN")
CHAT_ID = "YOUR_CHAT_ID"

async def main():
    print(await bot.send_message(CHAT_ID, "سلام از بله"))
    print(await bot.send_photo(CHAT_ID, "PHOTO_FILE_ID_OR_URL", caption="تصویر"))
    print(await bot.send_document(CHAT_ID, "DOCUMENT_FILE_ID_OR_URL"))

asyncio.run(main())

متدهای موجود

  • request(method, payload=None)، get_me()، get_updates(offset=None, limit=100, timeout=30, ...)
  • send_message(chat_id, text, **kwargs)
  • send_photo(chat_id, photo, caption=None, **kwargs)، send_document(chat_id, document, caption=None, **kwargs)
  • edit_message_text(chat_id, message_id, text, **kwargs)، delete_message(chat_id, message_id)
  • command(names)، message(flt=None)، callback()
  • start(timeout=30, retry_delay=2)، stop()، run(...)، event.reply(text, **kwargs)

برای عکس و سند از file_id یا URL استفاده کنید؛ آپلود فایل محلی با send_file در این کلاینت موجود نیست. راهنما · متدها

۳. سروش‌پلاس

واردسازی: from irubix import soroush · کلاس: soroush.IRubix یا soroush.Bot · خطا: SoroushAPIError

ساخت ربات و دریافت پیام

from irubix import soroush

bot = soroush.IRubix("SOROUSH_BOT_TOKEN")

@bot.command("start")
async def start(bot, event):
    await event.reply("سلام! ربات سروش‌پلاس فعاله.")

@bot.message()
async def messages(bot, event):
    if event.text:
        await event.reply(event.text)

@bot.callback()
async def buttons(bot, event):
    print(event.button_id)
    if event.callback_query:
        await bot.answer_callback_query(event.callback_query["id"])

bot.run()

ارسال متن، عکس و سند

import asyncio
from irubix import soroush

bot = soroush.IRubix("SOROUSH_BOT_TOKEN")
CHAT_ID = "YOUR_CHAT_ID"

async def main():
    print(await bot.send_message(CHAT_ID, "سلام از سروش‌پلاس"))
    print(await bot.send_photo(CHAT_ID, "PHOTO_FILE_ID_OR_URL", caption="تصویر"))
    print(await bot.send_document(CHAT_ID, "DOCUMENT_FILE_ID_OR_URL"))

asyncio.run(main())

متدهای موجود

  • request(method, payload=None, http_method="POST")، get_me()، log_out()، close()
  • get_updates(offset=None, limit=100, timeout=30, allowed_updates=None)
  • set_webhook(url, **kwargs)، delete_webhook(drop_pending_updates=None)، get_webhook_info()
  • send_message(...)، forward_message(...)، send_photo(...)، send_document(...)
  • edit_message_text(...)، delete_message(...)، answer_callback_query(...)
  • command(names)، message(flt=None)، callback()
  • start(timeout=30, retry_delay=2)، stop()، run(...)، event.reply(text, **kwargs)

برای رسانه از file_id یا URL استفاده کنید؛ send_file برای آپلود فایل محلی در این کلاینت وجود ندارد. Long polling و webhook را هم‌زمان فعال نکنید. راهنما · متدها

برای عکس و سند از file_id یا URL استفاده کنید؛ send_file در این کلاینت وجود ندارد. Long polling و webhook هم‌زمان قابل استفاده نیستند. راهنما · متدها

الگوی مشترک Event

@bot.message()
async def handle(bot, event):
    print(event.text)
    print(event.chat_id)
    print(event.message_id)
    await event.reply("پیام دریافت شد")

برای فیلتر پیام:

@bot.message(lambda event: event.text == "سلام")
async def hello(bot, event):
    await event.reply("سلام به شما!")

فیلدهای Event بسته به پیام‌رسان متفاوت‌اند؛ برای داده کامل رویداد از event.raw استفاده کنید.

نکات

  • روبیکا از from irubix import IRubix استفاده می‌کند؛ بقیه از ماژول اختصاصی خودشان.
  • برای اجرای ربات از bot.run() استفاده کنید.
  • توکن را در GitHub یا کد عمومی قرار ندهید.
  • متد send_file برای ارسال فایل محلی فعلاً مختص روبیکاست.
